Support & Help

Quick start

  1. Save one image: right-click any image → “Save image as…” → choose PDF, PNG, JPG, WebP or BMP.
  2. Combine images into one PDF: click the toolbar icon → “Combine images into one PDF” → click the images you want → Build PDF.
  3. Grab every image on a page: toolbar icon → “Grab images on this page” → Select all (or pick some) → Save.
  4. Adjust PDF layout: open Settings to set page size (A4 / Letter / fit-to-image), orientation, margins, image placement and quality.

Frequently asked questions

How do I save an image as a PDF? Right-click the image, choose “Save image as…”, then click PDF. The PDF downloads instantly.
Can I put several images into one PDF? Yes — this is the extension’s headline feature. Click the toolbar icon, choose “Combine images into one PDF”, select the images on the page, and press Build PDF. They become a single multi-page PDF.
My image looks blurry / pixelated in the PDF. That happens when a small image is scaled up to fill the page. Open Settings → PDF layout → Image placement and choose “Actual size (never enlarge)”. Small images then keep their real, sharp size.
Why does BMP or a format save differently than expected? BMP is written as a true 24-bit bitmap. If your browser can’t encode WebP, the file falls back to PNG to guarantee you still get a valid image.
An image failed to save. Some images are protected by the website’s login/session or a strict security policy and can’t be fetched directly. Try opening the image in its own tab first, then right-click and save. In batch mode, images that can’t be read are skipped.
Do you upload or see my images? No. All conversion happens on your device. Nothing is uploaded and there is no tracking. See the Privacy Policy.
Where do the files go? To your browser’s normal Downloads folder. Turn on “Ask where to save each file” in Settings if you’d rather choose the location each time.
